# 🏆 Mercado da Copa - Frontend

**Marketplace mobile de itens esportivos vintage** — Camisas antigas de seleção, bonés e casacos da Copa.  
Frontend responsivo com Tailwind CSS + JavaScript Vanilla, conectado ao Supabase (Auth, Realtime e Storage).

## ✨ Features
- 📱 Interface mobile-first e responsiva
- 🔐 Autenticação com Supabase Auth (login/cadastro)
- 🛒 Carrinho de compras persistente no banco
- ⚡ Atualizações em tempo real (Realtime)
- ⭐ Sistema de avaliações com rating 1-5 estrelas
- 🖼️ Upload de imagens para produtos (Storage)

## 🛠️ Tech Stack
- HTML5 + Tailwind CSS
- JavaScript Vanilla (ES6+)
- Supabase SDK
